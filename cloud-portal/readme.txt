سامانه پیشرفته پرتال مرورگر و نمایشگر وب برای وردپرس با معماری نامحسوس (Stealth)، کوکی‌جار RFC 6265، رمزگذاری آدرس‌ها و نوار ابزار Glype.

== Description ==
این افزونه یک درگاه نمایشگر صفحات وب و اسناد اینترنتی را به صورت کاملاً ایمن و مستقل بر روی وردپرس شما مستقر می‌سازد.
تمامی کدهای پروکسی و کلمات نشانه‌دار از دید مرورگر، هدرها و فیلترها حذف شده‌اند و از آدرس‌های رمزنگاری شده استفاده می‌شود.

== Installation ==
۱. فایل cloud-portal-wp.zip را از طریق منوی افزونه‌ها > بارگذاری افزونه در پیشخوان وردپرس نصب کنید.
۲. افزونه را فعال نمایید.
۳. برگه پرتال شما در آدرس yoursite.com/portal/ بلافاصله فعال می‌شود.
۴. همچنین می‌توانید از شورت‌کد [cloud_portal] در هر برگه یا المنتور استفاده فرمایید.
