نمایشگر صفحات وب برای وردپرس با پیوندهای کوتاه داخلی، سبک بارگذاری و نوار ناوبری شناور.

== Description ==
این افزونه امکان نمایش صفحات وب دلخواه را درون سایت وردپرسی شما فراهم می‌کند.
پیوندهای داخلی صفحات به‌صورت خودکار بازنویسی می‌شوند، نشست هر سایت جداگانه نگهداری می‌شود
و ترافیک خروجی از طریق لایه استاندارد HTTP خود وردپرس ارسال می‌گردد.

ویژگی‌ها:
* پیوندهای کوتاه مخصوص هر سایت (کلید اختصاصی هر نصب)
* نگهدارنده نشست سازگار با RFC 6265
* بازنویسی کامل HTML، CSS و JS شامل srcset و data-attributes
* نوار ناوبری شناور با گزینه‌های زنده
* محافظت از آدرس‌های داخلی شبکه
* سه لایه انتقال: WordPress HTTP API، cURL و Streams
* صفحه تنظیمات کامل در پیشخوان
* سطح دسترسی «مرورگر GLPE» — فقط کاربران دارای مجوز یا مدیران می‌توانند از نمایشگر استفاده کنند

== Installation ==
۱. پوشه glpe-viewer را ZIP کرده و از منوی افزونه‌ها > بارگذاری افزونه نصب کنید.
۲. افزونه را فعال نمایید.
۳. برگه نمایشگر در آدرس yoursite.com/view/ ساخته می‌شود.
۴. یا شورت‌کد [glpe_viewer] را در هر برگه یا المنتور قرار دهید.

= 4.9.0 =
* مستندسازی سازگاری سایت‌ها (تأییدشده با تست واقعی مرورگر): جدول کامل وضعیت انواع سرویس در README
* کپچای گوگل (صفحه «unusual traffic»): ابزار کپچا برای تأیید کلاینت واقعی طراحی شده است و در هر پروکسی وب از کار می‌افتد — محدودیت ساختاری همه پروکسی‌های وب است، نه نقص این افزونه؛ راه‌حل عملی: استفاده از IP سرور با سابقه تمیز یا ابزارهای اختصاصی
* وب‌اپلیکیشن‌های WebSocket-محور (مانند تلگرام وب): اپ روی WebSocket + Service Worker + IndexedDB سوار است که از طریق پروکسی HTTP قابل حمل نیست — محدودیت معماری
* پلیرهای استاندارد ویدیو/صدا (mp4/m3u8/فایل مستقیم): با عبور مستقیم رسانه (Range/206) به‌درستی کار می‌کنند — در نسخه ۴.۸.۰ آمده و اکنون مستند شد

= 4.8.0 =
* پخش ویدیوی یوتیوب: صفحات watch اکنون پخش‌کننده رسمی جاسازی‌شده را دریافت می‌کنند — ویدیو و تبلیغات قبل و بعد آن دقیقاً مانند سایت اصلی پخش می‌شوند (لینک‌های youtu.be هم پشتیبانی می‌شوند)

* عبور مستقیم رسانه: ویدیو/صدا (شامل درخواست‌های Range/206) بدون مصرف حافظه سرور به بازدیدکننده جریان می‌یابد — جستجو و پخش جزئی درست کار می‌کند
* توجه فنی: پخش‌کننده رسمی به‌صورت مستقیم از یوتیوب در مرورگر بازدیدکننده بارگذاری می‌شود؛ اگر شبکه‌ی بازدیدکننده دسترسی مستقیم به یوتیوب نداشته باشد، پخش از طریق این روش ممکن نیست (محدودیت سمت یوتیوب با پروتکل SABR/PoToken)

= 4.7.0 =

* بازیابی خودکار: اگر نشست مرورگر خالی باشد ولی حساب کاربری نسخه ذخیره‌شده داشته باشد، هنگام مرور به‌طور خودکار بارگذاری می‌شود — ورود به سایت‌های دیگر با ورود به حساب وردپرس همراهی می‌کند و به مرورگر/دستگاه خاصی گره نیست
* جداسازی کامل کاربران: هنگام خروج، کوز مرورگر پاک می‌شود؛ هنگام ورود، فقط نسخه ذخیره‌شده همان حساب بارگذاری می‌شود — کوکی‌های کاربران هرگز با هم ترکیب نمی‌شوند (تأیید زنده با دو کاربر)
* نمایش شمارنده کوکی‌های ذخیره‌شده در حساب در ویجت و صفحه مدیریت نشست‌ها + پیام تأیید پس از ذخیره
* پاکسازی کامل snapshot های حساب در هنگام حذف افزونه (uninstall)

= 4.6.0 =
* رفع کارنکردن دکمه‌های سایت‌هایی مانند google.com: در بازنویسی فرم‌های GET، فاصله بین نام تگ form و اولین ویژگی حذف می‌شد و خروجی «<formname="f">» می‌گشت — یک عنصر ناشناخته بدون معنای فرم؛ کادر جستجو و دکمه‌ها از فرم خارج می‌افتادند و کلیک هیچ اثری نداشت. اکنون جداکننده حفظ می‌شود و فرم سالم بازسازی می‌شود (تأیید زنده: دکمه Google Search جستجو را به سرور می‌فرستد)
* توجه: اگر از سرور با IP دیتاسنتر جستجو کنید، گوگل ممکن است صفحه «unusual traffic» (کپچا) نشان دهد — این سیاست ضد سوءاستفاده گوگل درباره سابقه IP سرور است؛ با IP عادی این صفحه ظاهر نمی‌شود

= 4.5.0 =
* سازگاری با اپلیکیشن‌های تک‌صفحه‌ای مدرن (YouTube): مسیریابی داخلی این اپ‌ها از طریق Navigation API و فراخوانی‌های سطح prototype انجام می‌شود که از pushState و location عبور می‌کنند — رهگیری کامل در سمت مرورگر اضافه شد (تاریخ pushState/replaceState هم در سطح prototype و هم نمونه، URL object ها، و رویداد navigate)
* ارجاع‌های هم‌مبدا داخل صفحات نمایشداده‌شده دوباره به سایت مقصد لنگر می‌شوند: فراخوانی‌هایی مانند new Request('/youtubei/v1/...') توسط مرورگر به دامنه خودِ ما حل می‌شدند و با خطای 404 مواجه می‌گشتند (صفحه «You're offline» یوتیوب) — اکنون درخواست‌های API با هویت دروازه به مقصد می‌رسند (تأیید زنده: پاسخ 200)
* فرم‌های GET هنگام رهگیری توسط SPA به پیمایش کامل با هویت دروازه تبدیل می‌شوند — جستجوی یوتیوب اکنون به صفحه نتایج کامل (رندر سمت سرور) می‌رود
* پوشش تگ‌های SCRIPT و LINK که به‌صورت پویا تزریق می‌شوند (اسکریپت پخش‌کننده ویدیوی یوتیوب) در ناظر DOM
* توجه: محدودیت سمت یوتیوب/گوگل — برای IPهای دیتاسنتر، یوتیوب ممکن است پاسخ‌ها را موقتاً محدود کند (صفحه خالی) یا گوگل صفحه «Couldn't sign you in» نشان دهد؛ این سیاست ضد سوءاستفاده سرویس‌ها است نه نقص افزونه

= 4.4.0 =
* رفع کارنکردن کلیدهای نوار ناوبری (بازنویسی پیوند / بدون اسکریپت / بدون تصویر / عنوان عمومی): رویدادهای درون‌خطی به دلیل پوشانده‌شدن سازنده URL توسط document.URL در سلسله‌مراتب اسکوپ، خطای «URL is not a constructor» می‌دادند — منطق کلیدها به تابع سراسری __glpeToggle منتقل شد
* رفع حذف‌شدن «$1» در اسکریپت نوار ناوبری: تزریق HTML با preg_replace باعث تفسیر $N به‌عنوان backreference و خرابی جاوااسکریپت می‌شد — اکنون با preg_replace_callback تزریق می‌شود
* رفع لودنشدن تصاویر بندانگشتی سایت‌های دارای srcset با پارامتر کامادار (مانند xhcdn): جداکننده کاندیداهای srcset فقط کامای همراه با فاصله است، نه هر ویرگول — طبق گرامر srcset پیاده‌سازی شد
* پاکسازی کدهای بی‌اثر intercept مربوط به location/top در اسکریپت سمت مرورگر (این ویژگی‌ها در همه مرورگرها LegacyUnforgeable هستند و قابل بازنویسی نیستند) — با توضیح مستند شد
* نکته: یوتیوب به‌دلیل معماری SPA و محافظت‌های سخت‌گیرانه مرورگر، پشتیبانی کامل از پخش در نمایشگر ندارد؛ حالت بدون اسکریپت فقط اسکلت صفحه را نشان می‌دهد
